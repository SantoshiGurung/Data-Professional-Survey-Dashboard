# Data-Professional-Survey-Dashboard
I built an interactive Power BI dashboard analyzing global survey data from over 600 data professionals. I cleaned the dataset to extract key insights regarding industry salaries, career entry difficulty, work-life balance, and popular programming languages, presenting the data in an executive-ready format
